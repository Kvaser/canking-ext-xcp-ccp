# DAQ Decoder

A CanKing data processor that starts DAQ on an XCP or CCP ECU and decodes the DAQ frames into signals, as described by
a JSON config.

Requires Kvaser CanKing 7.6 or later.

The DAQ Configurator workspace view adds and configures it. Using it on its own, with a saved or hand-written config,
is possible but not supported.
